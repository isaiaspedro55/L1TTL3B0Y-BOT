# 🤖 L1TTL3B0Y WhatsApp Bot

Bot de WhatsApp desenvolvido em Node.js usando a biblioteca Baileys.

O L1TTL3B0Y possui sistema de comandos, conexão via Pairing Code, painel de controle, banco de dados e ferramentas administrativas.

---

## 🚀 Funcionalidades

✅ Conexão WhatsApp via Pairing Code  
✅ Sistema de comandos com prefixo  
✅ Menu automático  
✅ Sistema de usuários  
✅ Banco de dados  
✅ Comandos administrativos  
✅ Sistema de permissões  
✅ Organização profissional em arquivos
